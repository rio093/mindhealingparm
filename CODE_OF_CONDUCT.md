# Code of Conduct · 행동 강령

**KO** 이 프로젝트의 모든 공간(이슈, PR, 토론)에서는 서로를 존중합니다. 배경, 경험 수준, 언어에 관계없이 누구나 참여할 수 있어야 합니다. 괴롭힘, 인신공격, 차별적 발언은 허용하지 않습니다. 문제가 있으면 저장소 관리자에게 이슈 또는 이메일(korrio093@gmail.com)로 알려 주세요. 관리자는 필요하면 댓글 삭제, 참여 제한 등의 조치를 취할 수 있습니다.

**EN** Everyone participating in this project — in issues, pull requests, and discussions — is expected to treat others with respect. People of any background, experience level, or language should be able to take part. Harassment, personal attacks, and discriminatory remarks are not tolerated. Report problems to the maintainer by issue or email (korrio093@gmail.com). Maintainers may remove comments or restrict participation when necessary.

This document is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
