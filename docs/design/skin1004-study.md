# Design study — skin1004korea.com (국내 레퍼런스) → 마음약방 v2

Analysed 2026-09-19 in a real browser (1457×812, desktop). **Role in v2: content order, menu, CTA and footer conventions for Korean users.** Visual style comes from [faithibiza-study.md](faithibiza-study.md).

## 1. 코드 사실

- 플랫폼: **Cafe24** 쇼핑몰 (jQuery + Swiper). GSAP/Lenis 없음. `<section>` 태그 0개, 시맨틱 헤딩 거의 없음(모두 `<p>`/`<span>`). 우리는 h1/h2 유지.
- 페이지 높이 **6,345px**. 이미지 131개, 영상은 Vimeo iframe 1개(1730×972, 자동재생 히어로).
- 폰트: **Montserrat**(영문 전부), 한국어는 GothamR/M 지정 후 **AppleSDGothicNeo**로 폴백. 영문 = 기하학적 산세리프, 한국어 = 시스템 고딕.
- 색: 흰 배경 `#fff`, 텍스트 `#353535`/`#191919`, 브랜드 브라운 `#3e230c`, 보조 `#463f33`, 회색 `#757575`, 금색 포인트 `#a8915f`(드물게). 배경색 블록 없음 — 색은 사진이 낸다.
- 헤더: **fixed, 흰 배경, 81px**. 좌 로고 / 중앙 GNB 6개 대문자 15px w400 ls .5px / 우 아이콘 3개(검색·계정·장바구니).
- 컨테이너 1,542px(뷰포트 1,728 기준 89%). 국내 몰답게 넓다.
- 버튼: "Learn More" = 1px 검정 테두리, r 30px, 투명 배경. 가격 옆 "SHOP NOW".
- 진입 시 **공지 팝업**("오늘 하루 열지 않기 / 닫기"), 우상단 플로팅 "↑" 버튼.

## 2. 섹션 순서 (국내 브랜드 몰의 표준 흐름)

| # | 구간 | 내용 |
|---|---|---|
| 1 | 히어로 | 풀블리드 Vimeo 영상 위 좌하단 텍스트: 부제(18px) / 타이틀(30px w700) / 아웃라인 필 "Learn More" |
| 2 | 캠페인 카피 | 중앙 정렬 한국어 2줄 |
| 3 | **핵심 제품 3열** | 라벨(12px) / 성분 헤드(26px w600) / 한 줄 효용 → 큰 제품 사진(배경 톤 3종) → 제품명 → **가격** → 호버 "SHOP NOW" |
| 4 | 무드 캠페인 | 풀블리드 모델 사진 + 우측 세로 썸네일 6개 |
| 5 | 인스타그램 | 타이틀 + 3열 정사각 피드 |
| 6 | 브랜드 가치 | 한국어 한 줄 → 3열 세로 사진 카드 |
| 7 | 푸터 | 3열: COMPANY INFO(상호·대표·주소·통신판매업신고·사업자등록번호) / CS CENTER(전화·상담시간·이메일) / PARTNERSHIP + SNS + AGREEMENT · PRIVACY POLICY · GUIDE |

## 3. 국내 관행으로 확인된 것

1. **제품과 가격이 두 번째 스크롤에 나온다.** 스토리보다 제품이 먼저. 판매 전인 우리는 같은 자리에 "스타터 키트 · 사전 관심 등록".
2. **GNB + 메가메뉴**. 단일 페이지인 우리는 3개(제품·진단·루틴)면 충분.
3. **헤더 우측은 아이콘**. 장바구니 대신 "사전 주문" 필 + GitHub 아이콘.
4. **성분/기능이 헤드라인**("매트릭실 10%"). 우리 대응물은 블렌드 노트와 상태어. 수치 표기는 클레임 가드 때문에 쓰지 않는다.
5. **한국어 카피가 짧다.** 섹션당 1–2줄.
6. **푸터 법정 정보 3열**. 항목명은 동일하게 두고 값은 "준비 중".
7. **팝업 공지·↑ 버튼**은 OSS 레퍼런스 페이지에는 소음 → 넣지 않음.
8. 영상 1개, 짧은 페이지, 배경색 블록 없음 → 어두운 밴드는 1개로 제한.

## 4. v2에 반영된 것

- 순서: 히어로 → **(01) 제품 3열 카드**(사진 + 라벨 + 헤드 + 한 줄 + "사전 관심 등록") → (02) 제품 정의 → (03) 루틴 → (04) 라이브 데모 → (05) 전환 2단 → 3열 푸터.
- 헤더: 로고 / 제품·진단·루틴 / GitHub 아이콘 + 사전 주문 필.
- 제품 사진: 실제 패키지 누끼를 브랜드 톤 배경에 재합성(`scripts/product-cutout.py`).
- 푸터: COMPANY INFO / CS CENTER / PROJECT / 사용 안내. 개인정보 처리 문구, 제품 분류·표시 기준 확인 문구 포함.
- 페이지 길이 약 8,000px(데스크톱), 영상 0개.

## 5. 가져오지 않는 것
