# 마음약방 랜딩 페이지

마음약방은 중요한 미팅, 발표, 클라이언트 피칭 직전에 꺼내 쓰는
흡입 전용 향 스틱과 1분 호흡 카드 기반의 준비 루틴 브랜드입니다.

이 저장소는 마음약방 v1 랜딩 페이지를 담고 있습니다. 제품 소개,
향 매칭 진단, 사전 주문 관심 등록 흐름을 정적 HTML, CSS, JavaScript로
구현했습니다.

## 핵심 메시지

**회의 모드 전환 스위치**

중요한 순간 직전, 코앞에 한 번. 3초. 향과 1분 호흡으로 만드는
나만의 준비 의식.

## 제품 구성

- 흡입 전용 향 스틱
- 1분 호흡 카드
- 2가지 블렌드
  - 포커스: 차분하게 정돈된 나를 선택하고 싶을 때
  - 샤프: 또렷하게 깨어있는 나를 선택하고 싶을 때

## 페이지 구성

- Hero: 브랜드 메시지와 주요 CTA
- 순간 공감: 영업·컨설턴트의 미팅 직전 상황
- 제품 소개: 향 스틱과 1분 카드 사용 순서
- 향 매칭 진단: 3문항 기반 블렌드 추천
- 신뢰 섹션: 실무 경험, 원료 기준, 국내 제조
- 사전 주문: 스타터 키트 구성과 이메일 등록
- FAQ: 사용법, 향 강도, 제형, 배송 안내

## 기술 구성

- `index.html`: 페이지 구조와 콘텐츠
- `styles.css`: 반응형 레이아웃, 디자인 토큰, 모션
- `script.js`: 모바일 메뉴, 스크롤 표시, 향 매칭 진단, 리드 폼

별도 빌드 도구 없이 브라우저에서 바로 실행할 수 있는 정적 웹 페이지입니다.

## 로컬 실행

```bash
python3 -m http.server 8765
```

실행 후 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8765/
```

## 카피 가이드

이 랜딩 페이지는 제품을 상황 전환 도구와 준비 루틴으로 설명합니다.
소비자에게 보이는 문구는 아래 원칙을 따릅니다.

- 상황, 정체성, 무드 중심으로 표현
- "정돈", "또렷", "전환", "준비", "루틴", "의식" 중심의 언어 사용
- 신체 지표, 질환, 의학적 주장으로 오인될 수 있는 표현은 사용하지 않음
- 제품 분류와 표시 기준은 최종 확인 절차에 따라 조정 가능

## 향 매칭 진단 로직

진단은 세 문항으로 구성됩니다.

1. 주로 언제 쓰고 싶은지 선택
2. 그 순간 원하는 나의 상태 선택
3. 끌리는 향 결 선택

추천은 두 번째 문항을 우선 기준으로 삼고, 세 번째 문항은 선호 신호로
기록합니다. 두 답변이 다를 경우에도 두 번째 문항을 기준으로 추천합니다.
